# Momentum — Goal Tracker

Goal-tracking web app. Companion to
[momentum-productivity](https://github.com/madhusudanpatnaik/momentum-productivity),
the fuller gamified productivity platform.

## Stack

React · TypeScript · Vite · shadcn/ui · Tailwind CSS

## Running locally

**Prerequisites:** Node.js 18+

```bash
npm install
npm run dev
```

| Command | What it does |
|---|---|
| `npm run dev` | Vite dev server |
| `npm run build` | Production build to `dist/` |
| `npm run preview` | Serve the production build |
| `npm run lint` | ESLint |
